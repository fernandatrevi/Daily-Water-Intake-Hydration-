# Daily-Water-Intake-Hydration-
El objetivo es clasificar el nivel de hidratación como Good o Poor
utilizando datos de consumo diario de agua y características personales.

## Etapas del análisis

- Revisión de datos vacíos, duplicados y valores atípicos.
- Selección de variables mediante Feature Importance y Permutation Importance.
- Comparación de SMOTE y RUS.
- Comparación de clasificadores con PyCaret.
- Entrenamiento y evaluación de un ensamble.
- Predicciones para nuevos registros.


## Datos

Daily Water Intake and Hydration Patterns Dataset de Kaggle.

https://www.kaggle.com/datasets/sonalshinde123/daily-water-intake-and-hydration-patterns-dataset
